# 賃貸物件ビューア（SUUMO）

自分の部屋探し用に、SUUMOの検索結果を取得してローカルの一覧画面で見るための小さなツールです。

> **注意:** このリポジトリは個人の部屋探しを補助するツールとして公開しているものです。取得したデータは含めていません。利用する場合は自己責任で、最新の利用規約を確認のうえ、下記「免責事項」を必ず読んでください。

## 対象サイトと方針

主要な賃貸ポータルは、いずれも個人が物件検索に使える公開APIを提供していません。そのため、プログラムで取得するには公開されている検索結果ページのHTMLを読み取る必要があります。

### SUUMOの利用規約について

[SUUMOご利用規約](https://cdn.p.recruit.co.jp/terms/suu-t-1003/index.html)（2025年10月1日改定版を確認）には、クローリングやスクレイピングを名指しで禁止する条項はありません。関係しそうな定めは次のとおりです。

- 第2条第1項: 著作権法で定める私的利用の範囲を超える使用の禁止
- 第3条第1項: 「本サイトの運営を妨げる行為」「商業目的で利用する行為」「その他当社が不適当・不適切と判断した行為」などの禁止

このため本ツールは、私的利用の範囲にとどめ、運営の妨げにならないよう次の方針で実装しています。

### robots.txt

検索結果ページ（`/chintai/<都道府県>/sc_<市区町村>/`）は、robots.txt の一般UA向け Disallow には含まれていません。`sort=` などの一部パラメータのみ明示的に禁止されています。

### 他サイト

at home、LIFULL HOME'S、CHINTAI、Yahoo!不動産なども個人向けの公開APIはありません（法人・不動産会社向けの連携APIはあります）。各サイトの規約は個別に確認していないため、対応させる場合は事前にそれぞれの利用規約を確認してください。

### 実装方針

**SUUMOのみ** を対象に、次の方針で実装しています。

- 個人の部屋探し目的に限定し、取得したデータを再配布・商用利用しない
- `robots.txt` で禁止されているパス・パラメータ（`/mb/`, `/jj/`配下の内部パス, `sort=`, `cinm=`, `snetid=` 等）へはアクセスしない
- 1ページ取得するごとに待機（既定2秒）を入れ、短時間に大量アクセスしない
- 「手動でボタンを押した時だけ」取得する（自動巡回・定期実行はしない）

他サイトを追加したい場合は、そのサイトの規約を確認したうえで、同じ方針（低頻度・個人利用・robots.txt順守）で `scraper/` に同様のモジュールを追加すれば、GUI側はほぼそのまま使い回せる構成にしてあります。

## 検索条件の設定

検索条件は `config.json` で指定します。リポジトリには例として [config.example.json](config.example.json) が入っているので、コピーして自分の条件に書き換えてください（`config.json` は `.gitignore` 済みでコミットされません。`config.json` が無い場合は `config.example.json` が使われます）。

```
cp config.example.json config.json
```

- `search_path`: SUUMOの検索結果ページのパス（例: `/chintai/tokyo/sc_musashino/`。SUUMOで市区町村を選んで検索し、URLを確認）
- `display_name`: 表示用のエリア名
- `madori_codes`: 間取りのチェックボックスに対応するコード（`06`=2DK, `07`=2LDK, `08`=3K, `09`=3DK, `10`=3LDK など）
- `target_towns`: 保存対象にする町名のリスト（例: `["吉祥寺本町", "中町"]`。空配列 `[]` にすると市区町村全域が対象）
- `page_size` / `max_pages` / `request_delay_seconds`: 取得件数・ページ数・待機時間

SUUMOには町丁目単位で絞り込む静的なURLパラメータが無い（JS/AJAXでしか選べない）ため、取得自体は市区町村全体を対象に行い、**取得したデータのうち `target_towns` の町名を含む住所だけを保存**する方式にしています。GUI側にも町名ごとのチェックボックスがあり、再取得せずに表示/非表示を切り替えられます。家賃の上限は設けておらず、GUI側で並び替え・絞り込みができます。

## セットアップ

```
pip install -r requirements.txt
cp config.example.json config.json   # 検索条件を編集
```

## 使い方

```
python app.py
```

起動すると自動的に既定のブラウザで `http://127.0.0.1:5000` が開きます。「最新の情報を取得」ボタンを押すと SUUMO から取得を開始します（数十秒〜数分かかります）。取得が終わると一覧に反映されます。

- 各列の見出しをクリックすると並び替え（家賃・専有面積・築年数など）
- 上部の検索ボックスで建物名・住所・駅名を絞り込み
- 賃料・専有面積の上限/下限を入力して絞り込み（片方だけの指定も可）
- 「㎡単価」列 = (賃料+管理費)÷専有面積。同じ間取りの物件を割安度で比べたいときは、間取りで絞り込んだ上でこの列でソートしてください
- 「詳細」列のリンクから SUUMO の物件ページを新しいタブで開けます

取得したデータは `data/listings.json` に保存され、次回起動時もそのまま表示されます（再取得ボタンを押すまでSUUMOへはアクセスしません）。`data/` は `.gitignore` 済みで、取得データはリポジトリに含めていません。

## スクレイパー単体での実行

GUIを使わず、コマンドラインだけで取得したい場合:

```
python -m scraper.suumo
```
